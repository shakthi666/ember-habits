# Ember — Habit Tracker & Streaks

A warm, simple habit tracker (Bloom design: soft violet + peach streak flames), monetized with Google AdMob.

Version 1.1: reminders, weekday schedules, skip protection, counter habits, per-habit colors, monthly calendar with editable history, 12-week trends, home-screen widget, offline backup/restore, reorder & archive, and 39 languages (26 European + 12 Indian + English). Light & dark mode, fully offline.

**Start with `SETUP_GUIDE.md`** — click-by-click, no coding.

| Path | What it is |
|---|---|
| `SETUP_GUIDE.md` | The complete, non-technical launch guide. Start here. |
| `lib/` | The app's code (untouched by you, except `ad_config.dart` once) |
| `lib/ad_config.dart` | The ONE file you edit — paste your AdMob IDs (Guide Part 5) |
| `admob_app_id.txt` | Paste your AdMob App ID here (Guide Part 5) |
| `.github/workflows/build.yml` | Build-robot instructions (GitHub compiles the app for you) |
| `assets/icon/` | App icon images (applied automatically at build) |
| `store_assets/` | Ready-made Play Store images (512 icon + feature graphic) |
| `docs/index.html` | Your privacy policy website (Guide Part 3 switches it on) |
| `pubspec.yaml` | App version & ingredients (edit only `version:` for updates) |

Built June 2026. App identity: `com.shakthi.ember_habits`. Replaces the earlier Calc Suite project (better category: daily opens → daily ad impressions).
